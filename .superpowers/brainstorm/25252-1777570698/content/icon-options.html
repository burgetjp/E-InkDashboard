Weather Icon Options

Three approaches — from simplest to most expressive. Each shows the full set of conditions we'd support.

A

Emoji — Simple & Zero Setup

Use Unicode weather emoji via a bundled font. No extra files, renders instantly. Limited to ~6 states.

☀️ ⛅ 🌛 ☁️ 🌧️ ⛈️ ❄️ 🌫️

Emoji rendering in Pillow requires a color emoji font (Noto Color Emoji ~10MB) bundled in Docker. Crisp at large sizes.

Pros

  • No extra API calls
  • Works offline
  • Familiar, colorful

Cons

  • Large font file in Docker
  • Emoji style may feel informal
B

NOAA Icons — Automatic & Always Accurate

NOAA returns an icon URL with every forecast. We fetch that image and composite it directly into the PNG. Zero mapping logic — NOAA picks the right icon.

← These are live NOAA icons

86×86px PNG, fetched during the hourly data refresh alongside weather data. Cached with the rest of the weather response. One extra HTTP call per hour.

Pros

  • Always matches forecast exactly
  • Covers every condition automatically
  • No mapping logic to maintain
  • Small file, no extra Docker deps

Cons

  • NOAA's icon style is dated/government
  • Fails if NOAA CDN is down (rare)
C

Custom Icon Set — Best Looking, Most Control

Bundle a small set of clean, minimal weather icons as PNGs (e.g. from Erik Flowers Weather Icons or similar). Map from NOAA's shortForecast text. ~10 icons covers 95% of conditions.

My recommendation: B (NOAA icons) — zero maintenance, always correct, one extra HTTP call per hour. But if the government-style look bothers you, C gives full control.
